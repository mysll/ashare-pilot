# ADR-0006：基于风险预算的仓位推导（草案）

- 状态：Proposed
- 日期：2026-07-30
- 范围：Daily 与 Intraday 策略输出的仓位语义；等级档的资金含义；个票相对大小与组合总敞口的推导规则
- 关联：[ADR-0004](0004-intraday-selection-pools-contract.md)（执行资格与双池）、[术语表](../glossary.md)
- 来源：2026-07-30 grilling 会话（intraday 迭代方向）

## 背景

旧数值仓位长期为 0.25%~1% 的极低值，由"分数→档位→规则削减"正向推导，
不锚定任何风险模型，被实盘判定为不具备参考价值，已由
`WATCH_ONLY / LIGHT / STANDARD` 定性等级替代。

但定性等级若不锚定资金含义，只是从"错的数字"变成"未定义的标签"：

- 2026-07-29 实例：中际旭创止损距离 -6.2% 与同花顺 -2.0% 被赋同一等级，
  个票实际风险相差约 3 倍；
- 2026-07 尾盘持仓实证期望为负（15 个持仓日合计约 -18.7pp，日均约 -1.2%），
  在 edge 未被证实前，Kelly 逻辑下诚实输出就是零仓；
- 用户确认：当前实盘仓位自行决定；若系统仓位有定义、可推导，愿意改用系统推荐。

## 决策

### 1. 仓位从止损反推，不从分数正推

```text
position_pct = risk_budget_pct ÷ effective_stop_distance_pct
```

- `risk_budget_pct`：单笔交易愿意亏损的组合净值比例，由等级档定义；
- `effective_stop_distance_pct`：入场价到止损价的距离，乘以 T+1 缺口系数；
- 止损价继续由技术结构决定（现有 `stop_loss_price` 机制不变）；
- 禁止以 `overnight_score`、`rank` 或任何与 T+1 收益已证负相关的变量决定仓位。

### 2. T+1 缺口系数

隔夜持仓最早 T+1 才能卖出，竞价缺口穿透止损是常态（如 7/21 铜冠 -9.97%
远超名义止损）。有效止损距离必须包含缺口放大：

```text
effective_stop_distance = nominal_stop_distance × gap_multiplier
```

`gap_multiplier` 初值 1.5，待切片测量校准；涨停邻近、高 ATR 标的适用更高系数。

### 3. 等级档映射风险预算（已校准）

| 等级 | 单笔风险预算 | 含义 |
|------|------------|------|
| `WATCH_ONLY` | 0 | 不建仓；edge 未证实切片默认落此档 |
| `LIGHT` | 1.0% | 有边缘证据或防御性参与；半仓角色 |
| `STANDARD` | 2.0% | 仅 edge 已被切片测量证实的场景 |

等级分配必须由验证后的 edge 切片驱动；测量完成前，所有可执行候选上限 `LIGHT`。

### 4. 持仓数与单只上限（已校准）

- 最多 **5 只** 同时持仓（hard cap）；
- 单只仓位 = `min(risk_budget ÷ effective_stop_distance, 20%)`；
- 会上限 = min(风险预算反推值, 等权分仓上限)；止损较宽时被 20% 封顶先咬合，
  实际单笔风险 ≤2%，天然构成对激进预算的二次约束。

### 5. Regime 组合热上限（Heat Cap）

组合总风险敞口 = 各持仓风险预算之和，按 regime 封顶：

| Regime | 最大持仓数 | 总风险预算上限 |
|--------|----------|---------------|
| strong | 5 | 10% |
| neutral | 3 | 6% |
| weak | 1 | 2%（或仅 LIGHT） |
| 极端弱市（I13 触发） | 0 | 0 |

超过上限时按等级与入场质量降序裁减，不压缩单笔止损宽度。
**Regime 门控是激进用户最关键的保护层**，2%×5 的最强配置仅限 strong regime。

### 6. 入场价定义

仓位计算的入场价取发布时快照价或买区锚定价，并在输出中明示所取价格与时间；
实际成交价偏离超过 ATR 的 0.5 倍时，股数应按实际成交价重算。

## 明确排除

- 不恢复 legacy 数值仓位合同；
- 不实现自动下单，输出为给人执行的股数/仓位建议；
- 本期不改变止损价的技术结构推导（MA5/MA10/MA20/day_low 机制不变）；
- 不在本 ADR 解决 edge 切片测量本身（见后续测量计划）。

## 待校准参数

- `gap_multiplier` 初值与分场景表（当前 1.5 起步）；
- regime 判定本身的准确性（当前 I21.a 等仍为候选规则）。

## 结果

等级档获得可推导、可审计的资金含义：同一等级下，止损距离远的标的自动获得
更小股数，个票风险归一；组合层面由 regime 热上限控制总暴露；在 edge 被证实
前系统输出自然收敛于 `WATCH_ONLY`，与"弱市不交易=最佳交易"的实证结论一致。
