# 每日交易报告 UI 改造说明

## 一、文件背景

当前页面文件：`daily_report.html`

页面标题为：

**每日交易报告 · 2026-07-09**

当前页面已经具备完整的数据结构，包括：

1. 市场状态；
2. 主题热度分布；
3. 策略方向分布；
4. 主题热力图；
5. 策略总表；
6. 单股推理详情；
7. 观察池；
8. 排除股票；
9. 引用新闻。

本次改造目标不是重写业务逻辑，而是基于现有 HTML 页面进行 UI 和信息层级升级。

---

## 二、整体改造目标

将当前“每日交易报告”升级为：

**A股每日交易决策总控台**

整体风格沿用此前确定的方向：

**Bloomberg Terminal × 投委会 Memo × A股量化策略看板**

页面应具备以下气质：

- 深色专业；
- 数据清晰；
- 决策优先；
- A股红涨绿跌；
- 主题主线突出；
- 规则和推理可追溯；
- 但不要让规则细节压过交易结论。

---

## 三、与隔夜策略页面的区别

此前的“隔夜策略决策看板”重点是：

- 是否隔夜；
- 执行几只；
- 总仓位多少；
- 明早开盘怎么处理；
- 止盈止损。

而本页面是“每日交易报告”，重点应改为：

1. 今日市场结构是什么；
2. 今日最强主线是什么；
3. 哪些主题可交易；
4. 哪些股票进入策略总表；
5. 哪些股票只是观察；
6. 哪些股票被硬过滤；
7. 哪些新闻支撑了今日判断。

所以本页不应做成单纯“个股执行卡片页”，而应做成：

**市场结构 → 主题主线 → 策略池 → 风险过滤 → 新闻证据**

的决策链路。

---

## 四、重要配色约束

### 1. 必须保留 A股红涨绿跌

本页面服务 A股交易语境，因此颜色语义必须符合 A股习惯：

- 红色 = 上涨 / 看多 / 偏多 / 强势 / 可交易；
- 绿色 = 下跌 / 走弱 / 排除 / 负向；
- 黄色 / 琥珀 = 谨慎 / 中等风险 / 需确认；
- 蓝色 / 青色 = 系统强调 / 主题科技感 / 信息提示；
- 灰色 = 中性 / 观察 / 不执行 / 低优先级。

不要改成美股常见的“绿涨红跌”。

### 2. 红色要分层

当前页面中红色承担了较多语义，改造时要区分：

- `--rise-red`：上涨、看多、可交易；
- `--danger-red`：高风险、硬过滤、不可交易；
- `--rise-red-soft`：看多标签背景；
- `--danger-red-soft`：风险标签背景。

避免页面整体显得“到处都是警报”。

## 五、推荐页面结构

建议将页面调整为以下结构：

1. 顶部标题区
2. 今日交易驾驶舱
3. 主线主题雷达
4. 策略总表
5. 重点策略池
6. 观察池
7. 风险过滤 / 排除股票
8. 新闻证据链
9. 页脚说明

其中：

- “今日交易驾驶舱”放最上面；
- “主题热力图”保留，但升级为主线主题雷达；
- “策略总表”保留，但字段需要重排；
- “单股推理详情”不要全部展开；
- “排除股票”不要直接长表全部展示；
- “引用新闻”要做成证据链，而不是纯文本堆叠。

## 十、重点策略池

当前页面有“单股推理详情”，但都是 details 折叠项。

建议新增一个模块：

**重点策略池**

位置：策略总表之后，单股推理详情之前。

### 展示对象

只展示前 5–6 个最重要标的：

- 5★ 标的；
- 综合分最高；
- 主题热度最高；
- 新闻催化最强；
- 或方向为“看多”的标的。

### 卡片字段

每个策略卡片展示：

1. 股票名称 + 代码；
2. 方向；
3. 评级；
4. 仓位；
5. 板块；
6. 综合分；
7. 入场条件；
8. 不买条件；
9. 核心逻辑一句话。

### 不要包含

- 日线图；
- K线图；
- MACD；
- RSI；
- 成交量图；
- 技术指标矩阵。

### 设计定位

该模块不是行情图卡，而是：

**交易指令卡 / 策略候选卡**

用户应该不用展开详情，也能快速理解每只核心标的的交易计划。

**新闻证据链**

### 目标

帮助用户理解：

## 十五、信息层级优先级

页面必须遵守以下信息优先级。

### 第一优先级

- 今日市场结构；
- 最强主题；
- 策略池数量；
- 看多 / 偏多分布；
- Top 策略标的。

### 第二优先级

- 主题热力；
- 策略总表；
- 入场条件；
- 不买条件；
- 主题证据。

### 第三优先级

- 单股完整推理链；
- 观察池；
- 排除股票；
- 规则编号；
- 原始数据源；
- 新闻编号。

不要让“排除股票”和“规则链路”压过页面核心交易结论。
