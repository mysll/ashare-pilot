# ISR-S001 规则可行性评审报告

- 版本：1.0
- 日期：2026-09-15
- 范围：14:30 尾盘影子规则 `ISR-S001 v1` 的前瞻证据与可行性判定
- 关联：[ADR-0008](adr/0008-intraday-shadow-rule-validation-contract.md)、[影子规则操作手册](runbooks/intraday-shadow-rule-operations.md)、[RULE_GOVERNANCE](../memory/RULE_GOVERNANCE.md)

## 1. 结论

**ISR-S001 v1 不可行，应冻结并重做。**

截至 2026-09-14，合同状态为 `continue_observation`，`market_day_count=11`。三个实质门槛
全部未通过；校准期的高表现属于过拟合，前瞻期的微弱优势不稳健且不具备统计意义。不建议
按“继续观察”空等——在规则现有触发率下，当前门槛几乎不可达。

本报告仅为评审，不修改任何规则、配置或代码。

## 2. 评审对象与数据来源

- 规则配置：`config/intraday-shadow-rules.json`（`ISR-S001 v1`，`frozen_on=2026-07-30`）
- 合同快照：`research/intraday-shadow/2026-09-14/shadow_rule_validation.json`
- 原始缓存：45 个交易日的 `.cache/intraday/{date}`（`compute_pool_enriched.json` +
  次一交易日 `all_stocks_cache.json`）

## 3. 方法

- 复用项目自身的 `_feature_row` / `_outcome` / `execution_state` 逻辑复算，保证与合同口径一致。
- 全量重建 3611 条合格样本（校准 1246 / 前瞻 2365），而非只分析命中子集。
- 定义**市场中性收益** `mark_rel` = 个股 T+1 14:30 标记收益 − 当日全池均值，用于隔离市场 beta。
- 标签为 T+1 14:30 标记价（非收盘价），成本假设 20bps，与配置一致。

校准→前瞻全面坍塌。阈值是在对该段历史有可见性的条件下选出的，属于典型过拟合形态。

## 5. 稳健性检验（前瞻期）

| 检验 | 结果 |
|---|---|
| 去掉 2026-08-03（当天 4 只全中） | 命中率 70% → **62.5%（低于基线 67.1%）** |
| 前半段 vs 后半段 | 80% / 中性 +0.49% vs 60% / **-0.98%** |
| 命中率 95% bootstrap CI | **[50%, 90%]**（覆盖基线） |
| 中性收益 95% bootstrap CI | **[-1.21%, +0.77%]**（覆盖 0） |
| 单日主导 | 8/03 贡献全部正收益，8/31 贡献主要负收益 |
| 校准期聚集 | 29 个样本中 13 个来自 7/09、8 个来自 7/29 |

结论：即便 70% 的命中率优于 67.1% 的基线，其差异完全落在噪声区间，且高度依赖单一交易日。

## 6. 门槛的统计功效问题

- 主标签“盘中最高价触及 +1%”的基础命中率为 **67.1%**；v1 观测 70%，差异在噪声内。
- 要在 67% 基数上证明 +10pp（→77%），单臂约需 **128 个命中样本**。
- 按当前 **约 1.8 只/触发日**，约需 **70 个触发日**。
- 即当前门槛在规则既有触发率下几乎不可达；继续空等没有效率。
- 另有口径问题：前瞻期 mean high=+2.75%，但 mean mark（T+1 14:30）=+0.08%，
  说明“冲高”不可捕获，主标签与经济收益脱节。

## 7. 条件级诊断（前瞻期，市场中性收益）

| 条件 | 命中率 | 中性收益 | 判断 |
|---|---|---|---|
| `vwap_gap 2–6%`（VWAP 强势） | 65.4% | **-0.19** | 负贡献 |
| `close_location ≥0.5` | 66.2% | -0.03 | 无信号（两期反向） |
| `change 0–5%` | 66.6% | +0.06 | 噪声 |
| `turnover ≤5%` | 68.8% | +0.13 | 唯一微正 |
| **v1 四条件合取** | 70.0% | **-0.25** | 反而不如单一低换手条件 |

“VWAP 强势 + 接近日内高点”的核心假设与数据不符；四条件组合甚至拖累了可交易指标。

## 8. 数据指示的改进方向（未经验证的假设）

跨校准、前瞻两期一致且留一法稳定的信号只有一组：**换手不过热 + 不过度偏离 VWAP**。

- 候选组合 `vwap_gap_pct ≤1.5 且 turnover_pct ≤8`：
  校准 +0.58 / 前瞻 +0.48；留一法区间 [0.39, 0.54] 全正；前/后半段均为正；n=614 / 28 日。
- 换手分桶近似单调：>12% 显著为负（-0.38），≤8% 为正。
- 注意：该组合的市场中性收益**中位数 ≈ 0**，优势来自尾部（规避左侧），并非每笔平均强势。

若开设 v2，建议：

1. 假设改写为“换手健康、价格未过度偏离 VWAP 的股票，T+1 回撤更小/守住涨幅优于同池基线”。
2. 条件保留 `turnover_pct`（带宽如 3–8），`vwap_gap_pct ≤1.5`；
   **删除 `close_location` 与 `vwap_gap 2–6%` 强势带**；`change_pct` 降为软条件。
3. 主标签改为**可交易口径**：T+1 标记净收益（或开盘收益）相对基线的提升；“冲高 1%”仅作辅助标签。
4. `frozen_on` 设为新版本启用日，**前瞻证据从零开始**；本报告所用窗口不得计入 v2 验证。

## 9. 建议动作

1. **冻结 v1**：保留全部历史合同不改写，记录判定为“未通过、不继续空等”。
2. v2 是否开设由人工决定；若开设，严格遵循 `memory/RULE_GOVERNANCE.md`。
3. 在人工批准前，禁止修改正式隔夜评分、mapper、`overnight_strategy.json` 生成逻辑，
   禁止把影子股票加入正式推荐，禁止将影子证据计入正式规则胜率。
