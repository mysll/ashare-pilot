# Sentiment 公式对非涨停潜力股的友好度分析

> 日期：2026-06-29  
> 背景：评估 `fetch_pool_indicators.py` 中 Sentiment 评分公式对「有潜力但未涨停」股票是否存在系统性偏见。  
> 相关实现：`.agents/skills/daily-stock-mapping/scripts/fetch_pool_indicators.py`
> 相关文档：`.agents/skills/daily-stock-mapping/SKILL.md` § Scoring

---

## 结论

**是的，对「有潜力但未涨停」的票，当前公式整体偏不友好**——尤其是启动初期、缩量蓄势、断板回调这几类。V5.1 加入 Market Sentiment 后有所缓解，但结构性偏向连板股的问题仍在。

若池子目标是「抓 tomorrow 的涨停候选」，这个偏向可以接受；  
若要覆盖「趋势启动、首板前夜、断板反包」，当前公式**明显偏严**。

---

## 当前公式回顾

```
sentiment = max(Board Sentiment, Market Sentiment)
tech_score = traditional × 0.70 + sentiment × 0.30
composite  = ... + tech_score × 0.20 + ...
```

Sentiment 对 composite 的有效权重约 **6%**（0.30 × 0.20），但在 tech_score 内部占 **30%**，对池内排序和 soft filter（≥50）影响显著。

### Board Sentiment（板情绪）

```
Board Sentiment = 连板强度 × 0.50 + 涨停频率 × 0.25 + 封板质量 × 0.25
```

| 因子 | 权重 | 评分规则 |
|------|------|----------|
| 连板强度 `board_streak` | 50% | ≥3板=100；2板=85；1板=65；0板=**0** |
| 涨停频率 `limit_up_freq` | 25% | 近10日：≥3次=100；2次=80；1次=60；0次=**0** |
| 封板质量 `seal_quality` | 25% | 封死=100；未封板=60；炸板=15；非涨停日=**0** |

### Market Sentiment（非板情绪，V5.1）

```
Market Sentiment = 换手率 × 0.40 + 阶段新高邻近度 × 0.35 + 5日均量比 × 0.25
```

| 因子 | 权重 | 评分规则 |
|------|------|----------|
| 换手率 `turnover` | 40% | ≥10%=100；5–10%=85；3–5%=70；1–3%=55；0.5–1%=35；<0.5%=20 |
| High20 邻近度 | 35% | close/h20 ≥0.99=100；≥0.95=85；≥0.88=65；≥0.75=45；<0.75=25 |
| 5日均量比 `vol_ratio_5d` | 25% | ≥2.0=100；1.5–2.0=85；1.2–1.5=70；0.8–1.2=50；0.5–0.8=35；<0.5=20 |

缺失数据时，对应因子默认 50 分（中性）。

---

## 核心原因：`max()` + Board 路径断崖

非涨停股在 Board 路径上几乎拿不到分：

| 因子 | 非涨停日得分 |
|------|-------------|
| 连板强度 (50%) | **0** |
| 封板质量 (25%) | **0** |
| 涨停频率 (25%) | 最多 25（近 10 日 3 次涨停） |

Board 路径上限约 **25 分**，必须靠 Market Sentiment 整条路径来救。

对比：1 板封死轻松到 **72.5**：

```
65×0.50 + 60×0.25 + 100×0.25 = 72.5
```

非涨停股要追上，Market Sentiment 需 ≥72.5，门槛不低。

### V3 → V5 断板信号退化

旧版（`SKILL_bak.md`）对断板日有额外处理：

- 昨日未涨停、前日涨停 → streak_s = **40**
- `limit_up_freq = 0` → freq_s = **20**（现为 0）
- 非涨停日 `seal_quality = "—"` → seal_s = **50**（现为 0）

新版对断板/非板日更 harsh，刚断板的龙头 Board 路径几乎归零。

## 哪类「潜力非涨停股」被误伤？

用当前公式模拟典型场景：

| 场景 | Market Sentiment | vs 1板(72.5) |
|------|------------------|--------------|
| 强势未板：+8%、换手 6%、距高点 96%、量比 1.6 | **85** | ✅ 能反超 |
| 趋势中继：+3%、换手 4%、距高点 92%、量比 0.9 | **63** | ❌ 差一截 |
| 启动初期：+5%、换手 3%、距高点 85%、量比 1.1 | **56** | ❌ 明显偏低 |
| 缩量蓄势：+2%、换手 1.5%、距高点 78%、量比 0.7 | **47** | ❌ 接近不及格 |

分类结论：

| 类型 | 描述 | 公式友好度 |
|------|------|-----------|
| A | 已经很强、接近涨停但没封板 | ✅ V5.1 能照顾 |
| B | 刚启动、距前高还有 10–15% 空间 | ❌ 天然吃亏 |
| C | 龙头断板、今日回调 | ❌ Board 只剩 freq（≤25） |
| D | 趋势慢牛、每天 +2~3% 从不涨停 | ❌ 长期 40–55 分 |

## 对 tech_score 的实际拖累

```
tech_score = traditional × 0.70 + sentiment × 0.30
```

举例（traditional ≈ 80）：

| sentiment | tech_score |
|-----------|------------|
| 0（断板归零 / 无 Market 路径） | **56** |
| 56（启动初期） | **73** |
| 72（1板水平） | **78** |
| 85（强势未板） | **82** |

同一只技术面不错的票，只因「今天没涨停、还没贴近新高」，tech 可从 78 掉到 56——**22 分差距**。soft filter 边缘（50–59 标 `tech_risk`）和池内排序都会受影响。

## V5.1 改善了什么、没改善什么

### 改善了

活跃但未涨停（高换手 + 贴近高点 + 放量）不再 sentiment=0。

### 没改善

1. **断板龙头**：昨日涨停、今日未板 → Board 只剩 freq 贡献（最多 25）
2. **启动初期**：距 high20 还有 10–15% 空间 → h20 子分 45–65，整体难超 60
3. **趋势慢牛**：每天 +2~3%、从不涨停 → 长期 sentiment 40–55
4. **不区分涨跌方向**：下跌日高换手仍可能拿高分（对阴跌股是 bug，对断板潜力股是副作用）
5. **与传统因子重复计分**：High20 邻近 vs BB Position、换手 vs Liquidity、量比 vs 动量，「高位+放量+活跃」被双重奖励

## 与 pipeline 目标的匹配度

| 场景 | 匹配度 | 说明 |
|------|--------|------|
| 连板龙头排序 | ⭐⭐⭐⭐ | Board 三因子设计到位 |
| 强势-day 未涨停 | ⭐⭐⭐ | V5.1 补了，但需同时满足高换手+近高点+放量 |
| 启动初期 / 首板前夜 | ⭐⭐ | High20 和换手门槛过高 |
| 断板 / 首阴龙头 | ⭐⭐ | V3→V5 退化，信号偏弱 |
| 趋势慢牛 | ⭐⭐ | 长期低 sentiment |
| 利空放量下跌 | ⭐ | 可能误高分（缺方向过滤） |
| 作为 composite 微调 | ⭐⭐⭐⭐ | 6% 权重下够用 |

## 改进建议（按优先级）

### P1 — 加「动量子分」（Momentum Sentiment）

用 `change_pct` 奖励「强势但未涨停」：

```
+3~7%（未达涨停阈值）→ 60–80 分
+1~3%               → 45–60 分
```

补启动期信号，不依赖 High20 邻近。

### P2 — 恢复断板衰减分

昨日未涨停但 `limit_up_freq ≥ 1` 或前日涨停 → streak_s = 35~40，而非 0。

### P3 — Market Sentiment 加方向修正

`change_pct < 0` 时，turnover / vol_ratio 子分 ×0.5（类似 auction 的 negative halving），避免放量阴跌被当情绪好。

### P4 — 输出拆分

保留 `sentiment = max(...)` 作排序用，同时输出：

- `board_sentiment`
- `market_sentiment`
- `sentiment_driver`（`"board"` / `"market"` / `"momentum"`）

Step 3 按类型走不同规则（如 R35 仅 board 路径触发）。

### P5 — 降低与传统因子重叠

- 缩小 Market Sentiment 在 tech 中的有效贡献，或
- High20 邻近与 %B 二选一，避免双重奖励「高位」

### P6 — 缺失数据改保守

Market Sentiment 缺因子时默认 50 → 改为 35~40，与 traditional 侧「缺失则跳过」策略一致。

## 附录：公式合理性总评（前序讨论摘要）

作为 A 股题材池的「情绪代理指标」，大方向合理，但存在结构性问题：

**合理之处：**

- Board + Market 双轨符合 A 股题材/游资结构
- 在 composite 中权重克制（~6%），定位为排序微调器
- 风险与情绪分离（炸板 → risk_flags，不 hard reject）
- R35 要求 `board_streak ≥ 1`，防止纯 Market 高分误触发连板探测

**主要短板：**

- `max()` 丢失情绪类型，两只 sentiment=85 的票含义可能完全不同
- 与传统因子部分重复计分
- 断板信号 V3→V5 弱化
- 换手率/量比不区分涨跌方向
- 阈值绝对化，缺少板块/市值归一化
